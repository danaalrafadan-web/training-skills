أربعة جداول بعلاقات ومفاتيح أجنبية وقيود CHECK و UNIQUE، وفهرس على التاريخ، و View يجمع حركات اليوم في صف واحد للتقارير.

  • الجداول والعلاقات والبيانات التجريبية: schema.sql

مخطط العلاقات (ERD)

جدول الحضور والـ View في SQL 
CREATE TABLE attendance (
  att_id      NUMBER GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  emp_id      VARCHAR2(20) NOT NULL REFERENCES employees(emp_id),
  att_date    DATE         NOT NULL,
  action      VARCHAR2(12) NOT NULL
              CHECK (action IN ('IN','BREAK_START','BREAK_END','OUT','OT_START','OT_END')),
  action_time TIMESTAMP    NOT NULL,
  device      VARCHAR2(20),
  CONSTRAINT uq_attendance UNIQUE (emp_id, att_date, action)
);

CREATE OR REPLACE VIEW v_daily_summary AS
SELECT e.emp_id, e.full_name, d.name AS dept_name, a.att_date,
       MAX(CASE WHEN a.action = 'IN'  THEN a.action_time END) AS check_in,
       MAX(CASE WHEN a.action = 'OUT' THEN a.action_time END) AS check_out
FROM employees e
JOIN attendance a       ON a.emp_id = e.emp_id
LEFT JOIN departments d ON d.dept_id = e.dept_id
GROUP BY e.emp_id, e.full_name, d.name, a.att_date;

التثبيت والنشر حسب المنصة

التثبيت: من Chrome، القائمة ⋮ ثم «تثبيت التطبيق»، أو تطبيق Android الأصلي (المهارة 7).
  1. النشر على Google Play: من Android Studio نسوي Build ثم Generate Signed App Bundle (.aab).
  2. نرفع الملف في Google Play Console مع الوصف والصور وسياسة الخصوصية.
التثبيت: من Safari، زر المشاركة ثم «إضافة إلى الشاشة الرئيسية».
  1. النشر على App Store: نغلف الموقع في تطبيق WKWebView بـ Xcode.
  2. نرفعه عبر App Store Connect، ويحتاج حساب Apple Developer وجهاز Mac.
التثبيت: من Edge على Windows، أيقونة «تثبيت التطبيق» في شريط العنوان.
  1. النشر على Microsoft Store: نولد حزمة MSIX من رابط الـ PWA بأداة PWABuilder.
  2. نرفعها في Partner Center.
ملاحظة: BlackBerry أوقفت أنظمتها ومتجرها (BlackBerry World) ولا عاد فيه نشر عليها. الموقع المتجاوب يشتغل على متصفح أي جهاز، وأجهزة BlackBerry الحديثة تشتغل بنظام Android فتنطبق عليها خطوات Android.

تطوير تطبيقات الأجهزة الذكية التي تعمل بنظام تشغيل Android

مشروع Android Studio بلغة Java: تطبيق يفتح نظام البصمة داخل WebView، ويعرّف نفسه للخادم كجهاز Android، وينبه الموظف إذا انقطع الاتصال.

  • الشاشة الرئيسية: MainActivity.java
  • الصلاحيات والإعدادات: AndroidManifest.xml، build.gradle
Android StudioJavaWebViewGradle
مقتطف من MainActivity.java 
public class MainActivity extends Activity {
    private WebView web;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        web = new WebView(this);
        setContentView(web);

        WebSettings s = web.getSettings();
        s.setJavaScriptEnabled(true);
        s.setDomStorageEnabled(true);
        s.setUserAgentString(s.getUserAgentString() + " AttendanceAndroid/1.0");

        web.setWebViewClient(new WebViewClient() {
            @Override
            public void onReceivedError(WebView view, WebResourceRequest req, WebResourceError err) {
                if (req.isForMainFrame())
                    Toast.makeText(MainActivity.this, R.string.offline, Toast.LENGTH_LONG).show();
            }
        });
        web.loadUrl(getString(R.string.server_url));
    }
}
